CLI para desarrolladores en Windows

Gestioná tusversionescomo un profesional

switchtool es un CLI en Go que te permite instalar, cambiar y administrar versiones de Java, Maven, Gradle, PHP, Go y Node.js en Windows sin tocar el PATH a mano. Descargá, extraé y configurá todo con un solo comando.

¿Cómo funciona?

Todo lo aburrido, automatizado

switchtool hace el trabajo pesado para que vos solo te preocupes por codear.

Descarga automática

Pasale una URL o un archivo local .zip, .tar.gz o .tgz. switchtool se encarga de bajar, verificar y descomprimir todo por vos.

PATH inteligente

Olvidate de editar variables de entorno a mano. Limpiá y actualizá el PATH de usuario con PowerShell automáticamente.

Variables de entorno

Setea JAVA_HOME, MAVEN_HOME, GRADLE_HOME, PHP_HOME, GOROOT y NODE_HOME en el registro de Windows sin que vos hagas nada.

Detección de raíz

¿El ZIP tiene una carpeta intermedia? switchtool la detecta y entra solito, así no tenés que mover archivos.

Cambio en un comando

Pasá de Java 17 a Java 21, o de Node 18 a Node 20, con un único comando: switchtool jdk21.

UI amigable

Colores, barra de progreso, spinners y mensajes claros para que instalar y cambiar versiones sea una experiencia piola.

Soportado

Un CLI para gobernarlos a todos

Java, Maven, Gradle, PHP, Go y Node.js. Descargá, instalá y cambiá de versión sin salir de la terminal.

Instalación

Instalalo en 4 pasos

Sin instaladores ni dependencias: un solo .exe y cuatro pasos.

  1. 1

    Descargá el binario

    Bajá switchtool.exe desde GitHub Releases. Es un único archivo: no necesita instalación.

    Ir a Releases
  2. 2

    Elegí una ubicación fija

    Guardá el .exe en una carpeta duradera, por ejemplo C:\Tools (evitá Descargas o Escritorio).

  3. 3

    Agregá la carpeta al PATH

    Corré esto en PowerShell (ajustá $dir si usaste otra carpeta), o hacelo desde Configuración → Editar variables de entorno del sistema.

    PowerShell
    $dir = "C:\Tools"
$path = [Environment]::GetEnvironmentVariable("Path", "User")
[Environment]::SetEnvironmentVariable("Path", "$path;$dir", "User")
  4. 4

    Reabrí la terminal y verificá

    Los cambios de PATH se aplican en las sesiones nuevas. Abrí una terminal y probá:

    Terminal
    switchtool --version

Y listo: se acabó el .\switchtool.exe

Con la carpeta en el PATH, escribís solo switchtool desde cualquier directorio. Si la terminal no lo encuentra, reabrila: es el paso que más se olvida.

Para desarrolladores

Compilá desde el código fuente

Si querés la última versión o querés contribuir, cloná el repo y compilalo con Go.

Build manual

Requiere Go 1.24+ instalado en tu sistema.

Go 1.24+
Terminal
git clone https://github.com/Programmercito/switcher-version-tools.git
cd switcher-version-tools
go build -o switchtool.exe .
Ver el repositorio en GitHub

Uso

Comandos que vas a usar todo el tiempo

Elegí un ejemplo y copiá el comando. La sintaxis es simple: tipo, alias y origen.

PowerShell

Descargá un JDK de Adoptium y dejalo listo para usar.

switchtool java jdk17 https://github.com/adoptium/temurin17-binaries/releases/download/jdk-17.0.9%2B9/OpenJDK17U-jdk_x64_windows_hotspot_17.0.9_9.zip
PowerShell

Instalá desde un .zip que ya tengas en disco.

switchtool php 8.2 C:\Downloads\php-8.2.10-Win32-vs16-x64.zip
PowerShell

Actualizá el PATH y las variables de entorno al instante.

switchtool jdk17
switchtool php8.2
PowerShell

Vé qué versiones tenés y cuál está activa.

switchtool list
# o
switchtool ls
PowerShell

Borra una versión del registro y del disco.

switchtool remove jdk17
